# Fanmake Pokémon Maps map packs

These archives contain the map images used by Fanmake Pokémon Maps during each
game's automatic setup. Archive names follow the compatible game version.

The app verifies the expected map count and SHA-256 before installation. A
complete existing map folder skips the download. Repair downloads the matching
archive again and replaces the installed maps.

Each ZIP contains only `Map###.png` or `Map###.webp` images.
